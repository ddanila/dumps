# PC1715W font selector: schematic excerpts

Unaltered crops from `1715W/teil_b/Stromlauf CRT-Steuerung B.jpg` in the
[source archive](https://xepb.org/robotron/docs/1715w.zip).
Drawing: CRT-Steuerung 1715W, `1.93.310412.6/04` (`56-331-0412-4`),
second scanned sheet.

The selector excerpt shows A05 address decoding, A07 latching DB4 as ZG2,
and E08 combining ZG2 with GPA0 by XOR. The surrounding preset/reset
circuitry is visible but is not fully modeled by the font-selector change.

Original JPEG dimensions: 2532 × 3517 pixels. Crop rectangles, expressed
as left/top/right/bottom coordinates:

- Selector: `(0, 1400, 1160, 2320)`.
- Drawing identification: `(900, 2790, 2460, 3340)`.

Crops were saved as PNG without rescaling, annotations or retouching.
